# DPO（Direct Preference Optimization）详解

> [[SFT.md]] 的 Q5 指出模仿学习的四个局限：只有正例、被数据质量封顶、压缩多样性、训练与推理错位 —— 这些都要靠偏好学习补。本文讲解偏好对齐的主流方法 DPO：它如何从 RLHF 的目标函数一步推出闭式解、绕开奖励模型与 PPO，用一个分类式损失直接在偏好数据上优化策略。内容包括核心公式推导、数值推演、关键超参（β 与参考模型）、与 RLHF 的对比及常见失败模式。

---

## 一、DPO 是什么

### 1.1 从 SFT 到偏好学习

[[SFT.md]] 解决了"让模型会回答"的问题，但 SFT 数据只告诉模型**应该输出什么**，没有告诉它**哪个输出更好**。偏好学习补的就是这块：

- **SFT 数据**：$(x, y)$ —— 一个 prompt，一个示范回答；
- **偏好数据**：$(x, y_w, y_l)$ —— 一个 prompt，一对回答，标注哪个更好（$w$ = chosen / winner，$l$ = rejected / loser）。

经典做法是 RLHF：先训一个奖励模型给回答打分，再用 PPO 强化学习优化策略 —— 管线长、训练不稳、超参敏感。DPO 的贡献是证明了：**在 KL 约束的 RLHF 目标下，最优策略与奖励函数之间存在闭式关系，可以把奖励"代入消元"掉**，最终得到一个只含策略模型与参考模型的监督式损失，训练稳定性和工程复杂度都大幅下降。

### 1.2 核心公式与物理含义

DPO 的损失函数是：

$$\mathcal{L}_{DPO} = -\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}}\left[\log \sigma\left(\beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\right)\right]$$

其中：

- $\pi_\theta$：正在训练的策略模型（通常从 SFT 模型初始化）；
- $\pi_{ref}$：**冻结的参考模型**（通常就是 SFT 模型本身），训练全程不变；
- $\beta$：KL 约束强度，同时充当隐式奖励的缩放系数，通常取 0.1 ~ 0.5；
- $\sigma$：sigmoid 函数；
- 对数概率 $\log \pi(y|x)$ 指整个回答序列的**累计** log 概率：$\sum_t \log \pi(y_t \mid x, y_{<t})$。

物理含义：**把"策略相对参考模型在 chosen 上的提升"减去"在 rejected 上的提升"，当作隐式奖励差，再用 sigmoid 把它变成一个二分类问题** —— 模型该给"chosen 比 rejected 好"这件事打多高的概率。

### 1.3 具象理解：两份答卷，老师只说哪份好

把对齐训练想成批改作文的两种方式：

| 组件 | 符号 | 物理含义 | 形象化描述 |
|------|------|----------|-----------|
| 策略模型 | $\pi_\theta$ | 正在学习的学生 | 学生本人，每次批改后调整写法 |
| 参考模型 | $\pi_{ref}$ | 冻结的 SFT 模型 | 学生"入学时"的水平快照，用来度量进步 |
| 优选回答 | $y_w$ | 标注者认为更好的回答 | 被老师圈出来的好答卷 |
| 较差回答 | $y_l$ | 标注者认为较差的回答 | 被退回来的差答卷 |
| 隐式奖励 | $\beta \log \frac{\pi_\theta(y \mid x)}{\pi_{ref}(y \mid x)}$ | 相对入学快照的进步幅度 | "比入学时写得好/差了多少" |
| KL 系数 | $\beta$ | 约束不要偏离参考模型太远 | 允许学生改风格，但不许推倒重来 |

**计算逻辑**（对一条偏好数据）：

1. **算进步**：chosen 和 rejected 各自的 log 概率，分别减去参考模型的对应值，得到两个"进步量"；
2. **比进步**：两个进步量相减，得到隐式奖励差；
3. **过 sigmoid**：奖励差越大，模型对"chosen 更好"的置信度越接近 1；
4. **算损失**：$-\log$ 置信度。置信度低（排序判错或不够自信）→ 损失大 → 梯度抬高 chosen、压低 rejected。

### 1.4 数值推演：走一遍完整流程

设定：$\beta = 0.1$，一条偏好数据的四个序列 log 概率为：

| 回答 | $\log \pi_\theta(y \mid x)$ | $\log \pi_{ref}(y \mid x)$ |
|---|---|---|
| chosen $y_w$ | $-5.0$ | $-6.0$ |
| rejected $y_l$ | $-8.0$ | $-6.0$ |

#### Step 1：算隐式奖励

$$r_w = \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} = 0.1 \times (-5.0 - (-6.0)) = 0.1$$

$$r_l = \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)} = 0.1 \times (-8.0 - (-6.0)) = -0.2$$

解读：策略相对参考模型把 chosen 的概率抬高了（+1.0 的 log 差），把 rejected 压低了（-2.0）——方向正确。

#### Step 2：奖励差过 sigmoid

$$\sigma(r_w - r_l) = \sigma(0.3) = \frac{1}{1 + e^{-0.3}} \approx 0.574$$

#### Step 3：算损失

$$\mathcal{L} = -\log 0.574 \approx 0.555$$

#### Step 4：同样的概率偏移，换 $\beta = 0.5$ 重算

$$r_w = 0.5, \quad r_l = -1.0, \quad \sigma(1.5) \approx 0.818, \quad \mathcal{L} \approx 0.201$$

**观察**：$\beta$ 直接放大奖励差 —— 同样的概率变化，$\beta$ 越大，sigmoid 越饱和、损失越小、梯度信号也越早消失。这就是 2.2 节"$\beta$ 是隐式学习率"的数值体现。

`★ Insight ─────────────────────────────────────`
**损失只管"相对进步"，不管绝对概率**：即使策略把 chosen 和 rejected 的概率都压低，只要 chosen 压得少，奖励差照样为正、损失照样下降。这解释了 DPO 训练中常见的现象 —— chosen 的 log 概率绝对值往往也在跌，只是 rejected 跌得更快。若需要抑制这一点，可在损失上加 SFT 项（$-\log \pi_\theta(y_w|x)$）正则，或用 DPOP 等变体。
`─────────────────────────────────────────────────`

### 1.5 推导直觉：奖励模型是怎么被消掉的

DPO 不是凭空设计的损失，而是从 RLHF 目标严格推出。链条分四步：

**第 1 步：RLHF 的优化目标**

$$\max_{\pi_\theta} \mathbb{E}_{y \sim \pi_\theta}[r(x, y)] - \beta \, D_{KL}(\pi_\theta(y|x) \| \pi_{ref}(y|x))$$

即在最大化奖励的同时，不许偏离参考模型太远（KL 惩罚）。

**第 2 步：最优策略有闭式解**

对固定的 $x$，这是带 KL 约束的最优化问题，可直接解出：

$$\pi^*(y|x) = \frac{1}{Z(x)} \pi_{ref}(y|x) \exp\left(\frac{r(x, y)}{\beta}\right)$$

其中 $Z(x)$ 是配分函数（归一化常数）。

**第 3 步：反解奖励函数**

把上式对 $r$ 反解出来：

$$r(x, y) = \beta \log \frac{\pi^*(y|x)}{\pi_{ref}(y|x)} + \beta \log Z(x)$$

**第 4 步：代入偏好模型**

偏好标注服从 Bradley-Terry 模型：$p(y_w \succ y_l \mid x) = \sigma(r(x, y_w) - r(x, y_l))$。把第 3 步的 $r$ 代入 —— **$Z(x)$ 只含 $x$，两项相减时精确抵消**，再把 $\pi^*$ 换成可训练的 $\pi_\theta$，对偏好数据做最大似然，就得到 1.2 节的 DPO 损失。

`★ Insight ─────────────────────────────────────`
**$Z(x)$ 的抵消是全局键**：配分函数 $Z(x) = \sum_y \pi_{ref}(y|x)\exp(r(x,y)/\beta)$ 要对整个回答空间求和，根本算不出来 —— 这正是 RLHF 必须显式训奖励模型的原因之一。DPO 的巧思在于只做"成对比较"：奖励差里 $Z(x)$ 自然约掉，不可算的项消失了。代价也随之而来：逐对比较用掉了"同一 prompt"这个条件，DPO 的归一化是隐式的，对分布外（OOD）输入没有 RLHF 那样的显式奖励信号兜底。
`─────────────────────────────────────────────────`

### 1.6 代码实现：手写 DPO 损失

```python
import torch
import torch.nn.functional as F

def sequence_logprob(model, input_ids, labels):
    """计算一条序列的累计 log π(y|x)：对 labels != -100 的位置求和。
    labels 里 prompt 部分置 -100（与 SFT.md 1.4 的 Loss Mask 完全同构）。"""
    logits = model(input_ids).logits[:, :-1]          # 预测下一个 token
    targets = labels[:, 1:]
    logps = torch.log_softmax(logits, dim=-1)
    token_logps = logps.gather(-1, targets.clamp(min=0).unsqueeze(-1)).squeeze(-1)
    mask = targets != -100
    return (token_logps * mask).sum(-1)               # [batch]

def dpo_loss(policy_w, policy_l, ref_w, ref_l, beta=0.1):
    """四个参数都是各序列的累计 log 概率（shape: [batch]）"""
    # 隐式奖励：r = β · log(π_θ / π_ref)
    w_rewards = beta * (policy_w - ref_w)
    l_rewards = beta * (policy_l - ref_l)
    # 偏好分类：σ(r_w - r_l) 应趋近 1
    return -F.logsigmoid(w_rewards - l_rewards).mean()

# 复现 1.4 的数值推演
loss = dpo_loss(
    torch.tensor([-5.0]), torch.tensor([-8.0]),
    torch.tensor([-6.0]), torch.tensor([-6.0]),
    beta=0.1,
)
print(loss.item())    # ≈ 0.555
```

## 二、关键组件与超参

### 2.1 参考模型 $\pi_{ref}$：KL 锚

参考模型是 DPO 的稳定器，作用有三层：

1. **定义"进步"的零点**：奖励不是绝对概率，而是相对 $\pi_{ref}$ 的变化量；
2. **防跑偏**：没有它，"压低 rejected"可以走极端 —— 把所有概率质量搬到某个奇怪回答上，同样满足奖励差为正。KL 锚保证策略不偏离 SFT 模型太远；
3. **保护通用能力**：等价于抑制灾难性遗忘。

实现上 $\pi_{ref}$ 冻结、只前向不反向，显存里要多放一份模型。用 LoRA 训练时可以省掉这份拷贝：把 adapter 关掉的前向就是参考模型的输出（`ref_model=None` 时 TRL 自动这么做）。

### 2.2 β 怎么选

| β | 效果 | 适用 |
|---|---|---|
| 0.05 ~ 0.1 | 约束松，偏离参考模型多，对齐力度强但易过拟合 | 偏好信号强、SFT 基座本身较弱 |
| 0.1 ~ 0.3 | **常用区间**，论文默认 0.1 | 绝大多数任务 |
| 0.5+ | 约束紧，几乎不动参考模型 | 只需轻微修正、严防退化 |

由 1.4 的 Step 4 可见，$\beta$ 同时是隐式奖励的缩放系数：调大 $\beta$ 与调大学习率的效果耦合。经验法则：**先用 0.1，发现输出退化（变长、变重复）就调大，发现对齐无效就调小**。

### 2.3 偏好数据的格式与质量

本质是一个个三元组：

$$\mathcal{D} = \{(x^{(i)}, y_w^{(i)}, y_l^{(i)})\}_{i=1}^{N}$$

常见 JSON 写法：

```json
{
  "prompt": "用一句话解释什么是过拟合。",
  "chosen": "过拟合是模型在训练集上表现好、在新数据上表现差的现象。",
  "rejected": "过拟合就是模型太复杂了，所以说复杂模型都不好。"
}
```

数据的三个来源与质量要点：

- **人类标注**：质量最高、最贵；两条回答最好来自同一模型采样（on-policy），差距要"明显但不悬殊"；
- **AI 反馈（RLAIF）**：用强模型（如 GPT-4 级别）打分构造，便宜量大，是当前主流；
- **规则构造**：如有标准答案的任务（数学、代码），对为正例、错为负例，可程序化生成了。

与 SFT 数据同理（[[SFT.md]] 1.3）：**质量优先于数量**，标注里的系统性偏差（如偏爱长回答）会被原样放大。

### 2.4 为什么先 SFT 再 DPO

DPO 的参考模型默认就是 SFT 模型，整个推导依赖"$\pi_{ref}$ 已经是个不错的策略"：

- Base 模型的回答分布太散，偏好对里的 chosen 可能离它的分布太远，梯度信号差；
- SFT 先把模型拉到"能用"的水平，DPO 只需在这个邻域内做偏好微调 —— 这与 1.5 节 KL 约束"不偏离太远"的假设一致。

直接对 Base 模型做 DPO（跳过 SFT）在简单任务上也能见效，但效果通常不如"SFT → DPO"两段式。

## 三、与 RLHF 的对比及变体

### 3.1 DPO vs RLHF（PPO）：流水线对比

| 维度 | RLHF（PPO） | DPO |
|------|------------|-----|
| 管线 | SFT → 训奖励模型 → PPO 强化学习 | SFT → 偏好数据直接优化 |
| 需训的模型数 | 3 个（策略、奖励、价值）+ 参考模型 | 1 个（策略）+ 参考模型 |
| 训练性质 | 在线 RL，需采样、打分、回传 | 离线监督式，等价于二分类 |
| 稳定性 | 差（PPO 超参敏感、reward hacking） | 好，与普通微调相当 |
| 显存 | 4 份模型同时在卡 | 2 份（LoRA 时 1 份） |
| 效果上限 | 略高（在线探索、显式奖励泛化更好） | 略低，但差距通常不大 |
| 迭代能力 | 可持续在线迭代 | 离线数据决定天花板 |

**结论**：DPO 赢在工程性价比 —— 把"三个模型 + RL 框架"压缩成"一次监督微调"；RLHF 赢在效果上限，头部实验室对齐旗舰模型仍用它。实际项目默认先 DPO，不够再考虑在线方法。

### 3.2 DPO 的局限

1. **长度偏置**：偏好标注普遍偏爱长回答，DPO 会把"变长"学成捷径，输出膨胀；
2. **chosen 概率也下降**：损失只管相对进步（见 1.4 Insight），可能把 SFT 学到的能力一起拉低；
3. **离线数据封顶**：不探索新回答，模型自己生成的新颖好回答得不到强化；
4. **对标注质量敏感**：奖励模型能平滑噪声，DPO 把每对标注当真值，噪声直接被学走；
5. **OOD 泛化弱**：隐式奖励只在偏好数据覆盖的分布内可靠。

### 3.3 主要变体

| 变体 | 改动 | 解决什么 |
|------|------|---------|
| IPO | 损失改为回归式，偏好概率直接拟合 1 | DPO 在确定性标注下过拟合 |
| KTO | 只需"好/坏"单条标签，不需成对 | 成对数据难收集的场景 |
| ORPO | SFT 损失 + 偏好损失合一，无参考模型 | 省掉 SFT/DPO 两阶段与参考模型 |
| SimPO | 用平均 log 概率当奖励，无参考模型 | 推理时长度归一，缓解长度偏置 |
| DPOP | 对 chosen 概率下降加罚项 | 3.2 第 2 条 |

这些变体的公共主题：**要么去掉参考模型省资源，要么修 DPO 的已知失败模式**，核心损失结构与 1.2 节一脉相承。

## 四、常见面试问题

**Q1：写出 DPO 的损失函数，并解释每一项。**

$$\mathcal{L}_{DPO} = -\mathbb{E}\left[\log \sigma\left(\beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\right)\right]$$

- $\pi_\theta$：训练中的策略模型；$\pi_{ref}$：冻结的参考模型（通常 = SFT 模型）；
- $\beta \log(\pi_\theta/\pi_{ref})$：隐式奖励 —— 策略相对参考模型的"进步量"；
- 两项相减：chosen 与 rejected 的奖励差；
- $\sigma$ + $-\log$：把对齐变成二分类 —— 模型对"chosen 更好"的置信度越高，损失越小。

一句话：DPO 把偏好对齐转化为"用隐式奖励差做逻辑回归"。

---

**Q2：DPO 为什么能绕开奖励模型和 PPO？**

因为 KL 约束下的 RLHF 目标存在闭式最优解 $\pi^*(y|x) \propto \pi_{ref}(y|x)\exp(r(x,y)/\beta)$，可以反解出 $r$ 用 $\pi^*$ 与 $\pi_{ref}$ 表示；代入 Bradley-Terry 偏好模型后，不可计算的配分函数 $Z(x)$ 在奖励差中精确抵消，奖励模型被"代入消元"掉了。于是不需要显式训奖励模型，也不需要在线采样的 PPO，直接在离线偏好数据上做最大似然即可（完整推导见 1.5）。

---

**Q3：参考模型起什么作用？去掉会怎样？**

参考模型是 KL 锚（见 2.1）：它把奖励定义为"相对 SFT 模型的进步量"，约束策略不偏离太远。

去掉它（相当于 $\pi_{ref}$ 换成均匀分布）后，"压低 rejected"不再有下限约束：模型可以把所有 rejected 类回答的概率压到趋零、把质量集中到少数模式上，表现为输出退化、多样性坍塌、通用能力遗忘。无参考模型的变体（ORPO、SimPO）能成立，是因为它们用其他机制补了这个锚（长度归一化、SFT 损失项）。

---

**Q4：β 的作用是什么？过大过小各有什么问题？**

$\beta$ 有两个身份：KL 约束的强度，和隐式奖励的缩放系数（1.4 的 Step 4 显示它直接乘在奖励差上）。

- **过小**：约束松，策略大幅偏离参考模型 → 输出变长、变重复、通用能力退化；
- **过大**：约束过紧，且奖励差被放大到 sigmoid 饱和区 → 梯度消失，对齐几乎无效。

常用区间 0.1 ~ 0.3，论文默认 0.1。调 $\beta$ 与调学习率效果耦合，一般先固定 $\beta = 0.1$ 调学习率。

---

**Q5：DPO 与 RLHF（PPO）怎么选？**

默认选 DPO：管线短（省掉奖励模型、价值模型、PPO 框架）、训练稳、显存省一半以上，效果与 RLHF 接近（完整对比见 3.1）。

需要 RLHF 的场景：追求极致效果上限的旗舰模型、需要持续在线迭代（模型自己探索新回答）、偏好信号需要显式打分复用的场合。头部实验室的最终对齐仍用在线 RL，DPO 更多是工业界与学术界的性价比之选。

---

**Q6：DPO 训练中发现输出越来越长、chosen 的概率反而下降，是什么原因？怎么办？**

两个都是已知失败模式（见 3.2）：

- **输出变长**：人类/AI 标注偏好长回答，模型把"变长"当成了拿高奖励的捷径。对策：数据侧做长度平衡采样，或换用长度归一化奖励的 SimPO；
- **chosen 概率下降**：DPO 损失只约束"chosen 相对 rejected 的进步差"，两者一起跌、chosen 跌得慢，损失照样下降（见 1.4 Insight）。对策：加 SFT 正则项 $-\log \pi_\theta(y_w|x)$，或用 DPOP 对 chosen 概率下降直接加罚。

排查时先看 chosen/rejected 两条 log 概率曲线的相对走向，再决定是数据问题还是损失结构问题。

## 五、总结

### 5.1 速查表

核心损失（与 1.2 节一致）：

$$\mathcal{L}_{DPO} = -\mathbb{E}\log\sigma\left(\beta\log\frac{\pi_\theta(y_w \mid x)}{\pi_{ref}(y_w \mid x)} - \beta\log\frac{\pi_\theta(y_l \mid x)}{\pi_{ref}(y_l \mid x)}\right)$$

| 概念 | 核心要点 |
|------|---------|
| 核心公式 | 见上式：隐式奖励差上的二分类交叉熵 |
| 本质 | 把偏好对齐变成隐式奖励差的二分类；监督式训练，无需采样 |
| 隐式奖励 | $r = \beta\log(\pi_\theta/\pi_{ref})$，即相对参考模型的进步量 |
| 推导关键 | RLHF 目标有闭式解 → 反解 $r$ → 代入 Bradley-Terry → $Z(x)$ 抵消 |
| 参考模型 | 冻结的 SFT 模型，KL 锚；防跑偏、防遗忘；LoRA 训练时可省显存 |
| $\beta$ | KL 强度 + 奖励缩放，0.1 ~ 0.3，默认 0.1；过小退化、过大饱和 |
| 偏好数据 | $(x, y_w, y_l)$ 三元组；人类标注 / RLAIF / 规则构造；质量优先 |
| 前置条件 | 先 SFT 再 DPO，$\pi_{ref}$ 就是 SFT 模型 |
| vs RLHF | 省掉奖励模型与 PPO，稳定性和显存大优；上限略低、不能在线迭代 |
| 已知失败模式 | 长度偏置、chosen 概率下降、标注噪声直通、OOD 弱 |
| 变体 | IPO / KTO / ORPO / SimPO / DPOP：去参考模型或修失败模式 |
